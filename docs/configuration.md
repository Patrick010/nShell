# Configuration

## UI Configuration
Accessible via Nextcloud Admin Panel:
- Shell selection
- SSH restrictions and allowed hosts
- Session timeouts
- Logging and audit settings
- Themes and prompt editor
- Optional advanced config editor

## Advanced Configuration
Optional `config/config.yaml` for power users.
- Default shell selection
- Allowed commands
- SSH restrictions
- Session timeouts
- Logging settings
- Themes, aliases, and prompts
