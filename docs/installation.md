# Installation

1. Download the latest nShell plugin:

```bash
wget https://example.com/nshell-latest.zip
```

2. Install via Nextcloud UI:
   - Go to **Apps → Install from file**
   - Upload `nshell-latest.zip`
   - Enable the app

3. Access nShell:
   - Navigate to **Terminal** in Nextcloud
   - Admins can configure settings from the **Admin Panel**

> nShell works immediately after installation with zero configuration.
