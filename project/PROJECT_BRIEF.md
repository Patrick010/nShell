# Project Brief

**Project Name:** nShell: Fully Configurable, Zero-Config Restricted Shell
**Date:** 2025-08-23
**Version:** 1.0

---

## 1. Project Objective

To build **nShell**, a user-friendly, fully configurable, and secure-by-default restricted shell environment for Nextcloud. It aims to provide administrators with powerful server management capabilities directly from the web interface, while enforcing safety and security through sensible defaults like `rbash`, session isolation, and command auditing.

## 2. Key Deliverables

- A backend daemon for session management and shell launching.
- A web-based frontend with an admin panel for configuration and a user terminal.
- A set of wrapper scripts for enforcing security restrictions (e.g., for SSH).
- A zero-config default setup that works out-of-the-box.
- Comprehensive project and user documentation.
