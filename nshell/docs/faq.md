# FAQ

**Q: Can users override the shell?**  
A: By default, no. Admins can allow other shells with warnings.

**Q: Are SSH restrictions mandatory?**  
A: Yes, for users by default. Admins can disable with warnings.

**Q: Does nShell require configuration?**  
A: No, it works zero-config out of the box.

**Q: Can I audit user sessions?**  
A: Yes, per-session logging and optional centralized audit logs.
